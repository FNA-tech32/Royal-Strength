# Royal Strength

Royal Strength is a single-page gym site. Visitors can read the membership offer, meet the trainers, browse classes, check the weekly timetable, and get in touch.

## Page

The site is one page, `index.html`. The menu jumps to these sections:

- **Home** — headline, “Get started,” and “learn more”
- **Membership** — a two-month offer at $60 per month, working hours, and a membership form
- **About Us** — a short introduction and two trainers (yoga instructor and body trainer)
- **Classes** — Yoga ($45), Aerobics ($60), and Cardio ($70)
- **Schedules** — weekday timetable for cardio, power fitness, boxing, aerobics, body work, power lifting, and crossfit
- **Contact** — message form, studio address, phone numbers, emails, and a map
- **Footer** — copyright and the same phone and email details

Sunday is closed. Monday to Friday is 7:00 AM–10:00 PM. Saturday is 6:00 AM–4:00 PM.

## Stack

HTML, Bootstrap, Font Awesome, AOS, and custom CSS in `css/main.css`. Scripts are in `js/`.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```
